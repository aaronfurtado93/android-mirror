Setup guide

1 · Turn on Developer options (once)

Settings › About phone › tap Build number seven times (Samsung: About phone › Software information › Build number).

2 · Pair over Wi-Fi (once per phone, Android 11+)

Settings › Developer options › Wireless debugging → on → Pair device with QR code, then use Add device › QR code here. After that the phone is remembered.

3 · Everyday use

Turn on Wireless debugging (tip: add the Wireless debugging quick-settings tile via Developer options › Quick settings developer tiles). This app spots the phone on the network and reconnects by itself — even when its port or IP address changed. Press Mirror.

Older phones (Android 10 and below)

Use Add device › USB cable and press Switch to Wi-Fi. Repeat after each phone reboot.

Something not working?

Press Troubleshoot on the device card. It checks adb, looks for the phone on the network by name and hardware address, follows a changed IP or port, cleans up stale connections and tells you exactly what to do if it still can't connect.

Guest Wi-Fi networks and "AP/client isolation" block phone↔computer traffic. VPNs on the phone can too.
